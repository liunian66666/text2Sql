# HR 第二业务域评测报告

## 评测口径

- 数据库：`enterprise_hr`，固定种子合成数据，截止日 `2026-10-28`。
- 模型：最终失败题复测使用 `deepseek-v4.1-flash-1017`；向量模型为 `qwen3.7-text-embedding-flash`。
- 每题从 `database_id=auto` 开始，检查自动选库、指标命中、工具策略、意图、SQL 关键语义和图表类型。
- 每题执行独立维护的 `truth_sql`，将 Agent 实际结果与数据库真实结果做规范化多重集比较，不只判断 SQL 是否能运行。
- 最终文件为增量失败题合并报告：保留已通过用例，只重跑失败项。因此总 Token 和平均耗时是各题最近一次通过记录的汇总，不等同于同一时刻进行的一次冷启动整批实验。

## 销售回归

接入 HR 后另跑 1 个 `database_id=auto` 销售问题：系统选择 `enterprise_sales`，返回 2026 年有效订单数 453，与可信 SQL 一致，并生成指标卡。最终回归 1/1，通过耗时 37.45 秒，32,907 Token。

## 修复记录

首轮暴露了三类真实问题：按数值排序被误判为“排名”、SQLite 整数除法使出勤率为 0、自动选库多占一轮后图表工具轮次不足。对应修复为：只在存在明确排名词时保留 ranking 意图；出勤天数字段改为 REAL 并在指标口径中强制浮点除法；工具轮次由 5 增至 6，并增加重复 SQL 调用提示。修复后失败题增量复测全部通过。
