# 50题失败案例分析

完整流程在固定 50 题上答对 38 题。以下 5 题覆盖主要错误类型，适合在面试中说明系统边界和下一步优化方向。

| 题号 | 数据库 | 错误类型 | 现象 | 可行改进 |
| ---: | --- | --- | --- | --- |
| 53 | california_schools | 聚合粒度误判 | 问题和标准答案要求返回各校考生数，生成 SQL 使用 `SUM` 合并为一个总数。 | 在选择器加入“答案是一行还是多行”的问题意图特征，并比较候选结果形状。 |
| 36 | california_schools | 投影字段不完整 | 标准答案返回最多三位管理员的完整姓名，生成 SQL 只返回第一位管理员姓名。 | Schema Linking 后增加投影覆盖检查，将问题中的复数实体与多组同前缀字段对齐。 |
| 1418 | student_club | 表与字段链接错误 | 应从 `budget.category` 取活动类别，却从 `event.type` 取值。SQL 可执行，但语义不正确。 | 候选选择时加入字段描述与证据匹配分，降低“同义列名猜测”的权重。 |
| 1451 | student_club | 统计口径错误 | 应按成员汇总 `SUM(cost)`，生成 SQL 按单笔最高支出 `MAX(cost)` 排序，并返回姓名而非成员 ID。 | 对“paid the most amount”生成 SUM/MAX 两类候选，再用问题分解结果选择。 |
| 1185 | thrombosis_prediction | 公式缺项 | 只计算 11 月与 12 月胆固醇差值，遗漏“下降率”所需的除法。 | 从提示和问题抽取显式计算公式，执行前检查公式中的分子、分母是否完整。 |

这些错误均属于“SQL 能执行但语义不对”。因此后续投入应优先放在结果形状、投影覆盖、聚合口径和公式完整性的验证，而不是继续增加无差别采样次数。
